# RUMPUS ENGINE — public_html/.htaccess
# Replaces the root .htaccess. Upload as ".htaccess" (with the leading dot) into public_html.
# Keep a copy of your current one first; if anything misbehaves you can put it straight back.
#
# WHAT CHANGED AND WHY
#  1. DirectoryIndex now lists TWO files. The old line named only breach.html, which REPLACES
#     Apache's default index.html — so /faq/, /compare/ and every other page folder made Apache
#     look for a breach.html inside them, find nothing, and return 403 Forbidden. (Verified live:
#     https://www.rumpusengine.com/faq/ returns 403 today.) Listing both fixes every folder at once.
#  2. Canonical host + scheme. http:// and the bare rumpusengine.com both return 200 right now, so
#     the same pages are reachable on four addresses. Search engines treat that as duplicate content
#     and split the ranking signals between them. These redirects pick one and send the rest to it.
#  3. CSS joins the long-cache list. It was the only static type missing.
# Compression is already on at the server level (breach.html is served gzipped), so nothing to add.

# ---------------------------------------------------------------- 1. which file serves a folder
# Order matters — Apache uses the FIRST one it finds.
#   index.html first  -> "/" is the marketing landing page, the game lives at /breach.html
#   breach.html first -> "/" stays the game; the marketing pages still work at their own paths
# The landing page forwards #lvl=, ?game= and ?challenge= to breach.html, so old share links keep
# working either way.
DirectoryIndex index.html breach.html

# ---------------------------------------------------------------- 2. one canonical address
# If your host terminates TLS at a proxy, %{HTTPS} can read "off" even on a real HTTPS request,
# which would cause a redirect loop. The X-Forwarded-Proto check below covers that case first.
# If you ever see "too many redirects", comment out this whole block and tell me.
RewriteEngine On

# http -> https
RewriteCond %{HTTP:X-Forwarded-Proto} =http [OR]
RewriteCond %{HTTPS} !=on
RewriteCond %{HTTP:X-Forwarded-Proto} !=https
RewriteRule ^ https://www.rumpusengine.com%{REQUEST_URI} [R=301,L]

# bare domain -> www  (the canonical tags on every page say www, so match them)
RewriteCond %{HTTP_HOST} !^www\. [NC]
RewriteRule ^ https://www.rumpusengine.com%{REQUEST_URI} [R=301,L]

# ---------------------------------------------------------------- 3. per-level share pages
RewriteRule ^game/([a-z0-9-]{1,64})/?$ game.php?slug=$1 [L,QSA]

# ---------------------------------------------------------------- 4. caching
<IfModule mod_headers.c>
  # The game and the marketing pages are small and change often — always revalidate.
  <FilesMatch "\.html$">
    Header set Cache-Control "no-cache"
  </FilesMatch>
  # Static assets are content-stable. If you edit rumpus-site.css, bump the link to
  # /rumpus-site.css?v=2 in the pages so returning visitors pick it up immediately.
  <FilesMatch "\.(css|js|svg|woff|woff2|glb|jpg|jpeg|png|webp)$">
    Header set Cache-Control "public, max-age=604800"
  </FilesMatch>
  # Crawler-facing text files: short cache so edits show up the same day.
  <FilesMatch "^(robots\.txt|llms\.txt|sitemap\.xml)$">
    Header set Cache-Control "public, max-age=3600"
  </FilesMatch>
</IfModule>

# ---------------------------------------------------------------- 5. no directory listings
Options -Indexes
