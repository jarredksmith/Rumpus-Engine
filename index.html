What is Rumpus Engine?

Rumpus Engine is a free, browser-based 3D game engine and level editor. You build games through a visual editor — no coding, no installation and no account — and share them as a URL that opens straight into a playable game.

It supports first-person and third-person shooters, racing and driving, top-down twin-stick and 2.5D side-scrolling games, with peer-to-peer multiplayer built in. The entire engine ships as a single HTML file built on three.js and the Rapier physics engine.

Why creators choose a browser engine

Most engines ask for a 10 GB download, an account and an afternoon of setup before you place a single cube. Rumpus Engine asks for a tab.

No setup

Open a link, start building

No installer, no launcher, no SDK, no project templates. The editor is live the moment the page loads, on whatever machine you happen to be at.

No code

Visual logic, not scripting

Trigger volumes, a node-based logic graph, persistent variables and branching dialogue. Build cause and effect by wiring it, not by learning an API.

Instant sharing

A level fits in a URL

Send a link and it opens as a playable game — no build, no export, no store page, no download for the person you sent it to.

Multiplayer

Co-op and PvP over WebRTC. Your level syncs to whoever joins, so you can playtest with a friend seconds after building it.

How to make a game with Rumpus Engine

  • Open the editor. Go to rumpusengine.com and choose Build / edit level. Nothing to install.
  • Shape the world. Sculpt terrain, drop in primitives, or search free 3D models and place them.
  • Set the rules. Pick a camera view and an objective — eliminate, survival, extraction, defend, destroy, escort, puzzle or race.
  • Add behaviour. Place enemy spawns, wire triggers to doors and events, write dialogue, script a cutscene.
  • Press play. P toggles straight between editing and playing — no build step, no compile, no waiting.
  • Share it. Copy a share link, export a file, or submit it to the community library.

Common questions

Is Rumpus Engine really free?

Yes. There is no paid tier, no subscription, no revenue share and no watermark on what you make. You do not need an account to build or to play.

Do I need to know how to code?

No. Everything is built visually — placing objects, sculpting terrain, wiring triggers, and a node-based logic graph for cause and effect. There is no scripting language to learn.

What do I need to run it?

A modern browser with WebGL — Chrome, Edge, Firefox or Safari on Windows, macOS, Linux, Android or iOS. There is nothing to install and nothing to keep updated.

Can I use my own 3D models?

Yes. Import .glb files, or search free models from Poly Pizza and Sketchfab without leaving the editor. Imported characters can be rigged and animated in the built-in animation editor.

Who owns the games I make?

You do. Levels are yours; asset licences follow whatever you imported, and the engine collects attributions per level and shows them on an in-game credits screen.
