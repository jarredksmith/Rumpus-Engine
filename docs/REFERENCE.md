# World & Scene Settings

Reference for RUMPUS ENGINE (`breach.html`, editor UI built in `renderEditorFields()` ~line 38448; world defaults in `DEFAULT_WORLD` ~line 17427). The **Scene** tab contains three sections: **Environment** (the world panel, `#edWorld`), **Auto-generate** (`#edGenerate`), and **Zones** (`#edZonePicker` + eight zone hosts). The Environment section is split into collapsible folds (Movement, Lighting, Camera & view, Sky, Floor, Walls, Arena, Audio); each fold's open/closed state persists per-browser in localStorage `breach_world_sections`. Every slider has a paired number box for exact entry; touching a control pushes an undo snapshot, and changes apply live via `applyWorldCfg()`. All values below save with the level unless noted.

One global compatibility note: levels saved **before build 1115** carry no `world.colorV` and render through `LEGACY_EXPOSURE` (authored against the old, darker colour pipeline); such legacy levels also default `skyMode` to `'flat'` (a flat fog-colour background, no gradient dome) unless the author opts in.

## Scene tab → Zones

Type picker — **⚡ Trigger · 🔊 Audio · ☠ Death · ⬆ Jump · 🪜 Ladder · 🔥 Fire · 💧 Water · ✨ Effect** — one panel at a time (persists in `breach_editor_zone`). Every panel: "+ Add … (at me)", per-zone select (gizmo on its dot) and ✕ delete. All zones carry to multiplayer.

**Trigger** — fires a Logic event on enter/leave/stay; does nothing alone (catch with an On event node). Fields: **fires** (event name, ≤60 chars; warns if empty); **when** Enters/Leaves/Stays in; **who** Player/Enemy/Anything; **radius** 0.5–400; **height** 0.5–200; **base Y** −500–500; **every (s)** 0.1–60 (Stays-in); **only once per match**.

**Audio** — positional ambient sound, full at middle, silent at edge; blue radius ring. **Sound** URL (▶ test), **Search Freesound**, **Radius** 3–90 (14), **Max volume** 0–100% (80%), **Loop** (on; off = once per entry), **Move here**.

**Death** — instant kill inside (lava, pits, OOB). **Radius** 1–60; **Lethal height** 0.5–40; **Base Y** −20–40 (auto-set on add). A lethal *plane*: you die only if feet are within Lethal height above Base Y — jumpable, but falling onto it kills.

**Jump pad** — launches players, bots, enemies straight up. **Bounce** 2–50 (a normal jump ≈13); **Radius** 1–60; **Band height** 0.5–40; **Base Y** −20–40. Fires when feet are in the band while landing/standing.

**Ladder** — vertical climb volume: W up, S down, jump hops off; at the top you step off the way the arrow points. Add while standing at the foot **facing your step-off direction**. **Height** 1–40; **Radius** 0.5–4; **Base Y** −20–40; **Step-off°** −180–180.

**Fire** — area on fire; anyone inside takes damage. **Damage/sec** 0–100; **Radius** 1–60; **Flame height** 0.5–40; **Base Y** −20–40. Transform: **Yaw°/Pitch°/Roll°** ±180 (pour from a wall/vent) + **Scale** 0.1–6 — visual only; the damage volume stays upright. Look: **Density** 0.3–2.5; **Particle size** 0.3–2.4; **Color hue** 0–360 (30 natural, 210 blue, 120 green, 285 purple); **Turbulence** 0–2.5; **Wind** −3–3; **Saturation** 0–1 (0 = grey smoke); **Sparks** (on); **Smoke** (off — dark occluding plume instead of glow).

**Water** — fills the cylinder to Base Y + Depth; deep = swim (Space up, **C** down), shallow = wade (slowed). **Radius** 1–120; **Depth** 0.05–20 (a puddle is 0.1); **Base Y** −20–40; **X/Z** ±2000; **Water color** (#14586e); **Opacity** 0.1–0.95; **Waves** 0–2.5; **Flow dir°** 0–360; **Flow push** 0–12 (current carries swimmers; chain zones for a river). Dynamic props float and bob; cars slow when submerged.
*Waterfalls* (in the Water panel): falling sheet + foam pool + positional sound. Per fall: **X/Z** ±2000; **Top Y** −20–80; **Drop** 1–60; **Width** 0.5–60; **Facing°** ±180; **Tint** (#bfe6f2); **Opacity** 0.1–0.95; **Speed** 0.1–4; **Splash** 0–2; **Pool width** 0.2–2.5; **Sound URL** (auto distance falloff); **Volume** 0–1. Standing in the sheet pushes you down into the plunge pool.

**Effect** — five effects: **heal, hurt, slow, haste, low gravity**. **Effect** dropdown; **Affects** players/enemies/both; **Amount** 0–200 (hp/s for heal/hurt, percent otherwise); **Radius** 1–120; **Base Y** −200–500; **Height** 0.5–80.

# Objects, Tools & Editor

The editor (toggled with **P** in-game) is one panel with nine **modes** — Build, World, Player, Enemies, Gameplay, Weapons, HUD, Save, Settings — each showing only its own sections and target tabs. A desktop menu bar (File / Edit / Tools / Help) mirrors panel actions; the panel can be resized (drag its edge, 260px–92% of the window), docked left/right (⇄), collapsed (⌄), or popped out into its own window (↗). A settings **search box** and the **Ctrl+K command palette** jump to any setting or action.

## The + Add menu

The floating **＋** button (or **Shift+A**) opens the one categorized menu for everything placeable. Each entry jumps to the owning mode/tab first so the new thing lands in view: **Box, Sphere, Cylinder, Cone, Ramp, Stairs, Light, Turret, Enemy spawn, Pickup pad ▸** (every pickup kind incl. keys), **Zone ▸** (Audio, Death, Jump pad, Ladder, Fire, Water, Effect).

# Game Systems, Logic & Sharing

## 1. The Logic Graph

Opened from the editor's **Logic** tab → "Open logic graph". A full-screen node canvas: drag the background to pan, wheel to zoom (40–160%), drag node headers to move, drag an OUT port onto an IN port to wire, click a wire to remove it. Parameters edit inline. Everything serializes with the level.

**Execution model:**
- Runs **host-authoritative** — clients never execute the graph; results reach them over the network.
- A per-frame **pulse budget of 400**; exceeding it (a wire loop without a Delay) pauses the graph for that frame with a toast, never the game.
- **Every value field accepts a number OR a variable name** (`5`, `-2.5`, `score` all work).
- **Event payload tokens**: inside the pulse cascade of an enemy or player event, `#x` `#z` (world position), `#hp` `#hpf` (enemy HP / fraction), `#pid` `#team` (player identity) are readable by Branch, Math, Set variable; the place field accepts `#here`. The payload is a snapshot — a Delay's later continuation runs without it.
- **Per-player variables**: a name ending in `@` (e.g. `coins@`) is scoped to the player the current event is about; solo/no-player pulses resolve to the host.
- `logicStart()` resets everything at deploy — variables, timers, node state, trigger arming, bent stats, music — then seeds carried values and fires On start.

### Variables that carry over (persistence)
In the Logic panel, every variable is listed with a checkbox:
- **Ticked = survives into the next campaign level.** Saved when a level is CLEARED — dying and retrying rewinds to entry values.
- **Also keep them between sessions** — browser-persisted so a returning player resumes.
  - **Carry the inventory too** (solo): keys/quest items/consumables come back; using an item saves.
  - **Resume at the last checkpoint** (solo): returning players continue; completing the game clears it.
- A live readout shows "carrying now: coins=12, …" with **Clear**.

### Custom HUD widgets
Author-defined on-screen elements, live views of graph variables (max 24): kind **text / timer / bar** (timer formats seconds as M:SS; bar fills value/max), label with `{var}` interpolation, `when` variable gates visibility, 8 anchors + pixel offsets, size 9–96, color, background. Host mirrors watched variables to clients so every player's widgets agree.

## 2. Signals on props

Every prop's **Signals** fold. A prop carries a **Tag** plus signals; **Needs** (1–20) = how many *different* senders must signal before it reacts (same sender twice counts once).

Each row: **When** `On destroyed` · `On E` · `On object placed`; **Do** (the full verb list above; world verbs take no target tag); **Target** a tag or `this`; **needs item** (+ consume) — On E with a missing item shows "LOCKED — NEEDS <ITEM>"; **On object placed** extras: object tag filter (blank = any physical prop), Touching it / Inside it, **Consume it** (the placed object vanishes when it lands). Open/Close/Toggle on a tag also drive tagged scene lights. Destroyed signals run only on the authoritative side; results broadcast.

## 3. Trigger volumes

A cylinder volume that fires a **Logic event** and does nothing on its own: **fires** (event name), **when** Enters / Leaves / Stays in (+ every s 0.1–60), **who** Player / Enemy / Anything, **radius** 0.5–400, **height** 0.5–200, **base Y** ±500, **only once per match** (re-arms on retry).

Player triggers are tracked **per player** — two players entering are two enter events, each carrying `#pid #team #x #z`; dying inside fires the exit edge. Enemy detection stays a union edge with no identity.

## 4. The Game panel (Objectives & rules)

### Objectives
**Eliminate · Survival · Extraction · Defend · Destroy · Escort · Puzzle · Race**
- **Eliminate** — clear waves; Win after N waves > 0 = clearing N wins.
- **Survival** — outlast a countdown (surviveSecs, default 120) while spawns keep coming.
- **Extraction** — a beacon drops across the arena; Hold seconds 1–30 (5), Zone radius 1.5–10 (3.5). Leaving resets progress.
- **Defend** — hold a zone for total time (10–999 s; clock pauses when empty), Zone radius 1.5–12.
- **Destroy** — destroy designated target props (HUD: DESTROY x/y).
- **Escort** — a payload rolls from spawn to the beacon; stay within Escort radius (1.5–12 m) to keep it moving.
- **Puzzle** — no enemies ever spawn; win via a Win-level signal. Pairs with Start unarmed + flashlight.
- **Race** — Laps 1–99 (3), AI rivals 0–6 (0 = time trial), Rival pace 0.4–1.3 (0.85 beatable, 1+ ruthless). Needs a Start-line track piece + a placed drivable vehicle; rivals clone a placed car.

### Wave settings
- **Wave mode**: **Random** (auto-spawns scaling with wave number: n = 3 + wave×2; mix widens at waves 3/5/8/12) or **Pre-built** (each wave spawns the markers assigned via "Appears on wave"; 0 = every wave).
- **No respawn (single pass)** — pre-built only; after the last authored wave clears, Eliminate wins.
- **Win after N waves** (0–99; 0 = endless).
- **Boss every N waves** (0–20; random mode; 0 = never).
- **Between-wave upgrade cards (solo)** — clearing a wave offers 1 of 3 upgrades.

### Authored wave manifests
A textarea (2000 chars), **one line per wave**:
```
3x grunt, 2x runner @gate
4x gunner, boss
-
```
Comma-separated terms `N x TYPE [@tag]` (the `N x` is optional — `boss` = 1). `@tag` clusters the squad on the tagged prop with the 1.5–4 m ring; no tag scatters at the arena edge. `-` alone = a breather wave. Blank manifest (or waves past its end) = the classic formula, so endless still escalates. Caps: 20/term, 40/wave, 2 bosses/wave, 50 waves. Unknown types demote to grunt; missing tags fall to the edge, never (0,0). Manifest waves never get the automatic milestone boss. The source text round-trips; the editor shows "Authored: waves 1–N · formula takes over from N+1".

### Enemy tuning
Per-type **hp / dmg / spd×** for every enemy type; blank = factory. Applies at spawn; saved with the level.

### Camera view
**First person · Third-person (chase) · Top-down · Side-scroller.** Top/side: Camera distance, Rotate°, Tilt° (89 = straight down), Height, Roll (dutch)°, Reset, live preview window + "Stand in it". Top-down extra: Players can orbit (middle-mouse, opt-in). Side extra: lane axis E–W / N–S. Chase extra: ARPG cursor aim (Diablo-style; middle-mouse swings the camera).

### Player / kit rules
- **Starts with** — any non-melee weapon (default rifle).
- **Start unarmed** (fists; G grabs/carries/throws) + **Allow picking up weapons found in the level**.
- **Flashlight** (L) with Brightness 0.5–20, Cone 8–60°, Edge softness 0–100%, Range 5–150 m, Beam colour.
- **Hit numbers** — floating damage numbers, font 10–120, Hit and Kill colors.

### World-rule blocks
- **Multiplayer spawn area** — circle (center, radius 3–200) or clicked outline polygon (3+ points, Top view).
- **Fall damage** — off by default; player and/or AI; minSpeed (24), perUnit (1.4).
- **Crush damage** — moving props hurt actors; minSpeed 7, perUnit 2.2.
- **Ragdoll** — physics corpses on enemy death.
- **Crosshair** — authored per level, carried to joiners: classic | cross | dot | circle | tee | none, size/thickness/gap/dot/color.
- **Goal text**, **Win/Lose text**, **Respawn on death** (solo respawn at checkpoint instead of game over).

## 6. Dialogue authoring

A prop with dialogue lines is a talkable NPC — E opens the box, steps lines; the first line fires its interacted signals. The world does not pause. One line per row; four marks make it branch:

| Mark | Meaning |
|---|---|
| `#label` | Names the NEXT row for jumps. |
| `> reply text -> label` | A reply button on the row above (`-> end` finishes; ≤6 buttons, keyboard 1–6). |
| `[if expr]` | Front of a row: skip unless true. End of a reply: hide it. |
| `-> label` | Jump instead of falling through; `-> end` ends. Only a lone label at row end counts. |

Inline: `{set name = 2}`, `{set name + 1}`, `{set name - 1}`, `{event name}` — the bridge to the graph. Conditions: `a OP b` (== != <= >= < >); sides are numbers, logic variables, or `item:someId` (count carried). Bare `[if hasKey]` = `>= 1`. Limits: 200 chars/line, 120/reply, 120 rows. A built-in lint warns about jumps to missing labels and branches that run into a labelled section.

## 9. Sharing & publishing

- **Save** — browser save (localStorage + self-healing IndexedDB copy); auto-loads next visit.
- **Export / Import** — a `.rumpus` file (JSON inside); import accepts `.rumpus`, `.breach`, `.json`. Format versioning: newer levels load with a loud warning; a `minV` above the client refuses cleanly.
- **Share link** — level gzipped → base64url: `…#lvl=<code>` (clipboard + length readout). Opens straight into the level.
- **Share codes** — `RUMPUSLVL:<encoded>` (legacy `BREACHLVL:` still accepted).
- **Challenge links** — `#lvl=…&chal=…`: level + your score target; offered on win/lose screens; the recipient's end screen shows the head-to-head.
- **Campaigns** — chain levels ("Add current level", reorder, Play campaign; weapons + health carry; persistent variables per §1). Export/import as one `.rumpus`; home-menu Play/Load campaign.
- **Community library** — "Publish to community": serializes with a screenshot thumbnail, level + author name, POSTs to the review server; approved levels appear in everyone's gallery (browse, play, open-to-remix). Server down → GitHub-issue fallback.
- **Instant game pages** — the Title screen section's publish: a `/game/<slug>` URL, no review, update-in-place, OpenGraph unfurls on Discord.
- **Creator title screens** — a level carries its own game title, tagline, accent, backdrop/logo, fonts, button labels, branded win/lose screens. Arriving via `#lvl=` or `?game=` shows THE CREATOR'S screen, not the engine menu.
- **Local models** — `local:` scheme is this-device-only; Level Check warns; the server upload is the "make it shareable" step.
